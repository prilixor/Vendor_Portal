7 Policies — Admin / Customer / Vendor Web Check

Walkthrough for Vidit and seniors  ·  11 September 2026  ·  Websites only (not mobile apps)

Live sites   Admin admin.blinksmed.com  ·  Customer www.blinksmed.com  ·  Vendor vendor.blinksmed.com

Only 7 policies. No 8th “Vendor Onboarding Agreement.” Vendor e-sign uses Vendor / Seller Policy. CMS text is the source of truth. Each accept logs the exact published version.

1. The 7 policies

# Policy Open this URL Customer Vendor Must accept?
1 Terms of Use /terms-and-conditions Show Show Yes — register
2 Privacy Policy /privacy-policy Show Show Yes — register. Extra tick if Unique ID or Rx file is attached
3 Vendor / Seller Policy /vendor-seller-policy Hide Show Yes — vendor register + onboarding typed-name e-sign
4 Rental & Purchase /rental-and-purchase-policy Show Can view (Settings / dashboard) Yes — customer checkout (one bundle tick)
5 Cancellation & Refund /cancellation-refund-policy Show Hide Yes — same checkout tick. Also on order / cancel
6 Shipping & Delivery /shipping-delivery-policy Show Hide Yes — same checkout tick. Also on product (pincode)
7 Grievance Redressal /grievance-redressal-policy Show Show No — display only (footer + Help)

Each URL should open title, version, date, and full CMS text — not “Page not found.” Use Ctrl+F5 if you see an old page.

2. Admin — manage and proof

  • ☐ Legal Documents — https://admin.blinksmed.com/admin/website-content/legal — all 7 Published
  • ☐ Open any policy → edit / draft / publish. Placement grid = where it shows and whether a tick is required
  • ☐ Legal Acceptances — https://admin.blinksmed.com/admin/website-content/legal/acceptances
  • ☐ After a test accept, a row shows: who, policy, version, screen (register / checkout / onboarding / reconsent), site (customer_web / vendor_web), IP, and signed name for vendor e-sign

Admin place-order for a customer skips customer legal ticks (admin is acting for them).
